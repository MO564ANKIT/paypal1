Monster artwork files go in this folder, one per monster, named exactly:

shopzilla.webp (or shopzilla.png)
coffeeling.webp (or coffeeling.png)
munchlord.webp (or munchlord.png)
saverion.webp (or saverion.png)
napcoin.webp (or napcoin.png)
impulso.webp (or impulso.png)

Use transparent backgrounds. WebP is tried first, then PNG. If a file is missing, the built-in drawing is shown instead.
